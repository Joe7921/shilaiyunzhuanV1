# 中文做菜复盘文字分类器

浏览器直接导入 `cook-model.ts` 的 `predictCookIssue(method, outcome)`。输入是实际做法与成品描述，输出包含标签、操作建议和命中的原句。模型、分句和建议都在设备上运行，模块没有外部依赖、图像输入、网络请求或跨次记录。

## 训练与推理

训练集 `corpus.txt` 含 194 条专门编写的模拟厨房口语，涵盖糊焦、过咸、夹生、过熟干柴、不成型或分离、成品成功六类。训练脚本按字符提取 1–3 元组，保留至少出现在两句中的特征，共 357 项。多类逻辑回归学习每个特征对六类的贡献，部署时将权重量化为百分之一精度。运行时仅累加当前句子出现的特征权重。

推理先区分实际反馈、否定、猜测、提问和超出范围的描述，再在有结果线索的分句上运行模型。首、次标签的分数差低于 0.60，或缺少两个以上字符的词片段证据时拒判。出现两个不同问题也会请用户单独描述一项。做法只用于已判定类别的建议，例如烘烤与炒锅采用不同的焦糊建议。结果页面适合标注“本地文字分类”；六类建议及其适配规则由人工定义。

## 可复现验证

当次运行使用 Python 3.12.14、scikit-learn 1.8.0、NumPy 2.3.5、Node.js 24.22.3。以下命令在本目录执行。

```sh
python train.py
node evaluate.mjs dev.tsv
node evaluate.mjs holdout.tsv
node smoke.mjs
```

`runtime.template` 存放推理代码。训练脚本只读训练集并写出完整 TypeScript 模块。训练、开发及独立留出三组文本逐字去重、彼此不相交。18 条开发样例用于小范围调试。独立留出文件在拟合前写定，一次性验证，未用来修订模型。

| 独立留出类别 | 正确 / 样例 |
| --- | --- |
| 糊焦 | 6 / 8 |
| 过咸 | 8 / 8 |
| 夹生 | 8 / 8 |
| 过熟干柴 | 5 / 8 |
| 不成型或分离 | 6 / 8 |
| 成品成功 | 8 / 8 |
| 应当拒判 | 16 / 16 |
| 合计 | 57 / 64，89.1% |

七条错误均为本可分类的反馈被拒判。在 48 条有具体标签的描述中返回了 41 个标签，覆盖率 85.4%。16 条应拒判的例子全部拒判。所有例句均为原创模拟文本，尚未通过独立采集的真实用户反馈评估。逐例结果在 `holdout-results.json`。另有 12 项接口、否定、做法细分与确定性验证，均通过。

含反讽、复杂否定、具体方言、歧义、多问题同句和未见过比喻时仍可能误判。能可靠分析的范围由六个文本类别限定，不能判断照片内容、食品实际温度、是否安全可食或身体状况。评分差值只用于内部拒判，不能解释为真实概率。
