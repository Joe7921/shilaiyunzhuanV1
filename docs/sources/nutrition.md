# 食材属性、时令与身体情况筛选

七类选项仅为用户自选的饮食偏好和食材匹配。应用先运行用户忌口和过敏原过滤，再将所有已选情况取交集，最后按菜谱真实投料排序。推荐理由和避雷提示只采用已声明食材信息。没有按身高体重计算能量目标，也没有测量每道菜的血糖生成指数、嘌呤、铁或乳糖含量。

| 情况 | 页面采用的处理 | 核验出处 |
| --- | --- | --- |
| 减脂 | 优先搭配蔬菜、蛋白质食材、全谷物和杂豆，甜饮靠后。避免低热量单菜代替正餐。 | [中国居民膳食指南（2022）核心推荐](https://wjw.fujian.gov.cn/ztzl/jkjy/jkzgxd/202206/t20220615_5930367.htm) |
| 长痘 | 优先含蔬菜、全谷物、豆类的配方，甜饮和甜点靠后。具体反应因人而异，不把辣椒、乳制品统一列为禁食。 | [美国皮肤科学会](https://www.aad.org/public/diseases/acne/causes/diet) |
| 痛风 | 当前自动推荐保守跳过内脏、红肉、部分海鲜、含酒菜、肉汤和含糖饮料。蔬菜和豆腐继续进入备选。疾病状态复杂时应按个人医嘱安排。 | [国家卫生健康委食养指南](https://www.nhc.gov.cn/wjw/c100378/202402/afd5dda4bd6745fda10aad8d43a16369.shtml)；[NIAMS](https://www.niams.nih.gov/health-topics/gout/diagnosis-treatment-and-steps-to-take) |
| 经期 | 优先有铁来源和搭配维生素C蔬果的配方，保留用户自主温度偏好。经量大、持续乏力宜核实缺铁原因。 | [美国卫生与公众服务部女性健康办公室](https://womenshealth.gov/a-z-topics/iron-deficiency-anemia) |
| 乳糖不耐 | 自动推荐保守跳过普通含奶食谱。乳糖不耐与牛奶蛋白过敏是不同的筛选条件，过敏原先行。 | [美国国家糖尿病、消化和肾脏疾病研究所](https://www.niddk.nih.gov/health-information/digestive-diseases/lactose-intolerance/eating-diet-nutrition) |
| 素食 | 本站使用蛋奶素口径，排除肉鱼及其汤汁、明胶和缺少来源信息的动物凝乳酶。 | [英国国家医疗服务体系](https://www.nhs.uk/live-well/eat-well/how-to-eat-a-balanced-diet/the-vegetarian-diet/) |
| 清真 | 仅展示可自行核验的植物或蛋类候选；跳过未经核实的肉品、酒及可疑动物辅料。没有对菜谱或成品做清真认证，访客需核对实际包装、复合配料和厨具。 | [美国农业部](https://www.fna.usda.gov/tefap/halal)；[IFANCA 配料核对指南](https://ifanca.org/resources/halal-shoppers-guide-to-ingredients/) |

## 时令与节气

- [香港渔农自然护理署《本地优质渔农产品四季食谱》](https://www.afcd.gov.hk/tc_chi/publications/publications_others/files/Four-season_Recipes_of_Local_Agricultural_and_Fisheries_Products.pdf)列明华南地区常见果蔬及相应季节。华南秋冬菜心、西兰花、芋头和萝卜，春夏芦笋、冬瓜、黄瓜、通菜等是编写本专区的参考。部分食材可全年栽培或跨区供应。
- [农业博物馆“二十四节气与饮食”](https://www.ciae.com.cn/Uploads/nybwg/nybl/essjq/jqkp/kpwz13.html)为习俗表述的主要参考。其他节气文案作为对应季节的家常烹饪建议。节气日期沿用原站香港天文台实测日历，本模块只处理季节内容。
- [安徽省旌德县市场监管局春笋消费提示](https://www.ahjd.gov.cn/Jczwgk/show/3523935.html)用于核对鲜笋的选购与充分加热说明。
- 板块中的传统饮食属性描述常见食法、口感与烹调传统。没有拿传统分类推断临床效果、适用疾病或绝对禁忌。
